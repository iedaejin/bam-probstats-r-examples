# Probability and Statistics — R examples

R code shown in class for **Probability and Statistics**, Bachelor in Applied Mathematics (BAM & BIEBAM), IE University, Spring 2027.

Each folder is one session. Open its README for the topic, readings and scripts. The computer labs are in a separate repository: [bam-probstats-labs](https://github.com/iedaejin/bam-probstats-labs).

## Getting started

1. Install R and RStudio (or use Posit Cloud).
2. Install the course packages once: run `install_course_packages.R` from the [labs repository](https://github.com/iedaejin/bam-probstats-labs).
3. Download this repository (*Code → Download ZIP*) or a single file, open it in RStudio and run it.
